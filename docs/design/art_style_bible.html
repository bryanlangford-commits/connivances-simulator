Art Direction · Style Bible

Connivances Art Bible

One locked visual identity for every card portrait; a high-fantasy world seen through an East-Asian lens; plus the exact Midjourney recipe to produce it and the path into Godot.

The Look

High fantasy, told in a Japanese key. Muromachi-era Japan meets myth; lacquered leather over plate, rice terraces over wheat fields, diviners over bishops.

The world leans Sengoku Japan; samurai and ashigaru, shrine and paddy, oni and ryū; but the arcane classes may drift toward a broadly Northern-European wizardry, so the sages and summoners read as a blend rather than pure one culture. Everything is painterly and weathered, never glossy anime cel-shading and never English-knight plate-and-portcullis.

Armor: lacquered leather lamellar (kozane), dō-maru Land: terraced rice paddies, thatched minka Faith: torii gates, ofuda talismans, miko Beasts: yōkai, oni, serpentine ryū Palette: indigo · persimmon · moss · ochre · charcoal Accent: a single vermilion note Texture: sumi-e ink-wash

Do

  • Single subject, centered, strong silhouette
  • Weathered materials; wood, paper, lacquer, hemp
  • Muted earthy palette, one saturated accent
  • Dramatic directional light + atmospheric haze
  • Painterly concept-art brushwork

    • Don't

  • European full plate, gothic castles, portcullises
  • Bright anime cel-shading or glossy 3D render
  • Busy backgrounds that fight the subject
  • Any text, border, frame or watermark in the image
  • Rainbow saturation; keep it grounded
    • The Constant

    The Locked Style Suffix

    This tail goes on every card, unchanged. You only ever swap the subject clause in front of it. This; not the subjects; is what makes 100 cards look like one game.

    append to every prompt
    painterly high-fantasy illustration, single centered subject, three-quarter view,
strong silhouette, dramatic directional lighting, warm key light with cool rim light,
volumetric atmosphere, muted earthy palette of indigo persimmon moss-green ochre and
charcoal with a single vermilion accent, subtle sumi-e ink-wash texture, weathered,
grounded, painted trading-card art --ar 4:3 --style raw --v 7 --sref YOUR_CODE --sw 90 --no text, border, frame, watermark, signature
    FlagValueWhy
    --ar 4:3landscape-ishMatches the art window in your frames; the frame masks the edges, so keep the subject centered.
    --style rawonLess of Midjourney's auto-prettifying, more faithful to your prompt.
    --v 7latest, fixedUse the current version; but pick one and never change it mid-set, or the look drifts.
    --srefyour locked codeThe cohesion anchor. Same code on every card. (See the ritual below.)
    --sw 90style weightHow hard the sref pulls. ~90 keeps subjects legible while staying on-style; lower if faces get muddy.
    --no …negativesKeeps text/borders out of the art; your frame provides all of that.

    Auspice banners are the one exception: use --ar 16:9 instead of 4:3, since they're wide full-art cards.

    Cohesion

    The sref Ritual; do this once, first

    Before generating a single card, you establish the one style reference every card will share. Half an hour here saves a hundred mismatched cards later.

    Generate hero candidates

    Run the locked suffix with 3–4 different subject clauses (a samurai, a paddy, a diviner); but without any --sref yet. You're auditioning the look, not the card.

    Pick the one that nails it

    Choose the single image whose mood, palette and brushwork feel most "Connivances." Upscale it.

    Lock its style code

    Grab that image's style reference; drag it into the prompt bar and Midjourney gives a --sref code (or use the image URL directly). That number is now sacred.

    Bolt it onto everything

    Every subsequent card prompt ends with that same --sref YOUR_CODE. Never regenerate it. If you ever want a fresh look, you restart the whole set; so commit.

    Optional discovery trick: run --sref random a few times to stumble onto a look you love, then read the code it used and lock that.

    Per-Guild Direction

    What each guild actually looks like

    Swap only the front clause of the prompt. Below: the visual vocabulary per guild, plus one ready example each (add the locked suffix to every one).

    Warriors 武士samurai · ashigaru · lacquered leather

    Not plate; kozane. Lamellar leather armor, dō-maru, sashimono back-banners, menpo masks; yari spears, naginata, katana. Foot-soldiers to daimyō. Siege units pair with great wooden war-engines.

    Farmers 百姓rice paddies · mino & kasa · water buffalo

    Rice, not wheat. Terraced flooded paddies (tanada), straw mino raincoats and wide kasa hats, thatched farmhouses, harvest baskets, mirror-still water. Peaceful, earthy, working the land.

    Diviners, blended. Onmyōji reading the stars, shrine miko with mirrors and bells, paper talismans (ofuda), astrolabes; free to shade toward a long-robed, bearded Northern-European sage. Candlelit, contemplative.

    Conjurers 召喚師summoners · shikigami · yōkai familiars

    Callers of spirits. Summoners binding shikigami paper-spirits and yōkai; ink brush and talisman in hand. Their conjured creatures are yōkai-tinged; spirit-fowl, foxes, oni-kin; rather than western monsters.

    Miya-daiku, not masons. Temple carpenters and engineers; construction of white-plaster castle keeps (tenshu) on stone bases, timber scaffolding, cranes, siege engines with an Eastern silhouette. Walls & forts are Japanese castles.

    The Recipe

    How to build any card prompt

    One formula, every time: a specific subject clause, then the locked suffix. Keep the subject to what fills the frame; pose, materials, one environmental hint.

    the formula
    [SUBJECT: one figure or scene, specific pose, East-Asian material cues, one environment hint], [LOCKED STYLE SUFFIX] --sref YOUR_CODE
    Auspice banners (Harvest / Mystic / Famine / Hunter) are wide scenes, no single figure required, and use --ar 16:9: 
    Golden terraced rice paddies at harvest, laborers gathering sheaves, warm autumn light … --ar 16:9 --sref YOUR_CODE
Withered dead rice paddies under a grey sky, bare black trees, a lone hooded reaper … --ar 16:9 --sref YOUR_CODE
    Production

    Midjourney, step by step

    Subscribe on a plan that allows commercial use & relaxed hours

    Standard or Pro. This is a game, so you need commercial rights; those come with paid plans. Standard's unlimited "relaxed" generations are ideal for a 100-card batch; you don't need fast-GPU speed.

    Work in the web app

    midjourney.com is easier than Discord for a big batch; grid view, easy re-runs, easy downloads. Set your defaults (version, style raw) once in settings.

    Run the sref ritual

    Lock your one --sref code first (see above). Everything after this reuses it.

    Generate card by card

    Paste the formula, swap the subject clause, submit. You get a 4-image grid. Pick the best; if none land, tweak the subject clause and re-run; the style holds because the suffix is fixed.

    Upscale & download

    Upscale the chosen image, then download the upscaled file (~1024px+ is plenty for screen; you can super-resolve later for print).

    Name by card id

    Rename each file to its card id: w1.png, bg4.png, mn_dragon.png. This is the filename your frame loads; get it right and the art drops straight in.

    Keep the batch consistent

    Same --sref, same --v, same --ar across the whole deck. If you change any of them, the set stops matching.

    Handoff

    Into Godot

    The art/<id>.png folder is portable; the same files the HTML sim loads import straight into Godot. Nothing you generate is throwaway.

    PieceIn Godot
    The portraitsDrop art/cards/<id>.png into res://. Godot auto-imports as textures; set filter on, mipmaps for smooth scaling.
    The art windowA TextureRect (keep-aspect-covered) inside the card scene, sized to your frame's window. Because every portrait is 4:3, one mask fits all.
    The frameA NinePatchRect or a StyleBoxFlat in a Theme, tinted by class (gold/red/maroon/silver); you don't need frame images; reproduce the CSS frame as a StyleBox, same as the sim.
    Icons & totemSmall TextureRect/Sprite2D nodes for crest, globes, flame, guild totem; or a font-icon Theme.
    The dataA custom Resource (CardData) holding stats + a Texture2D reference, so one data object drives name, numbers, tint, and portrait together; mirrors the sim's card objects.

    Rule of thumb: generate at a consistent size and aspect now, and the same assets serve the prototype today and the Godot build later.
